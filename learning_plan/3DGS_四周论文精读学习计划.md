# 3DGS 四周论文精读学习计划

适用背景：有一定线性代数基础和实际操作经验，但对 3DGS 的数学、渲染和优化细节缺少系统理解。

最终目标：读懂 Kerbl 等人的《3D Gaussian Splatting for Real-Time Radiance Field Rendering》（2023），能解释核心公式、算法设计及实验结论，并把主要步骤对应到实现。

## 学习主线与投入

按依赖关系学习：**场景表示 → 相机投影 → 像素合成 → 可微优化 → 自适应密度控制 → 高效光栅化 → 实验证据**。

建议每周 10–12 小时，共 40–48 小时。每天的安排可理解为五次学习，每次约 2 小时，另留 0–2 小时补缺口。沿用原计划的投入量，但将时间集中到论文理解。

每次学习都走一遍：提出问题 → 阅读对应段落 → 补所需数学 → 手算或小实验 → 合上材料复述。已有操作经验用于验证理论，不要求重新安装环境或完整训练大场景。

核心产出只有三份，四周持续补充：

1. `paper_notes.md`：逐节记录“问题、方法、依据、疑问”。
2. `formula_notes.md`：每个核心公式的符号、维度、推导、假设和几何意义。
3. 一个 notebook：从单个高斯到多个高斯的投影、混合和小规模拟合。

## 第 1 周：一个高斯究竟表示什么？

**目标：能从位置、旋转和尺度构造一个三维高斯，并解释颜色和不透明度的角色。**

论文阅读：摘要、Introduction、Overview；精读第 4 节的高斯表示部分。Related Work 先浏览，知道它与点云、网格、NeRF 的区别即可。

### 五次学习

1. **先建立问题框架。** 写出输入是什么、输出是什么、训练与渲染各做什么；画出从多视角图像与已知相机到新视角图像的流程。区分“优化一个场景的参数”和“训练跨场景通用网络”。
2. **补协方差的几何意义。** 复习对称矩阵、特征分解、正定性和二次型。画二维椭圆，说明特征向量决定方向、特征值决定各方向方差；轴长与特征值的平方根相关。
3. **读懂高斯核。** 从一维推广到二维、三维，理解马氏距离。区分用于 splatting 的未归一化高斯核和积分为 1 的概率密度；不用把条件概率、最大似然整章补完。
4. **读懂协方差参数化。** 推导旋转与尺度怎样生成协方差；理解为什么直接优化任意矩阵会带来无效形状。复习四元数表示旋转的直觉和归一化，暂不手推完整四元数梯度。
5. **理解外观。** 理清不透明度与颜色的区别；把球谐看作方向函数的基展开，掌握零阶颜色和高阶方向变化的区别。画一张参数表：参数、维度、约束、改变它会出现什么现象。

### 必须能解释的公式

$$
G(x)=\exp\left[-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)\right],\qquad
\Sigma=RSS^TR^T.
$$

其中 $\mu\in\mathbb R^3$，$R$ 为三维旋转矩阵，$S=\operatorname{diag}(s_x,s_y,s_z)$。严格正尺度下协方差正定；尺度趋近零时会有数值问题。不要把尺度和方差混为一谈。

### 小练习与验收

用 NumPy 绘制三个二维高斯：圆形、轴对齐椭圆、旋转椭圆。逐个改变尺度和角度，在图上标出主轴。

通过标准：不用材料解释“为什么是椭球”“为什么需要协方差的逆”“为什么旋转后会出现非对角项”“为什么高斯颜色能随视角变化”。交付一页表示笔记和三张图。

## 第 2 周：三维高斯怎样变成一个像素的颜色？

**目标：独立走通世界坐标 → 相机坐标 → 屏幕椭圆 → alpha 混合。**

论文阅读：精读第 4 节的投影和合成公式；第 6 节先看流程，暂不陷入 GPU 细节。

### 五次学习

1. **明确坐标约定。** 用列向量和 world-to-camera 外参写出变换；复习针孔模型。均值需要旋转和平移，协方差在线性坐标变换中只受旋转影响。
2. **手推投影 Jacobian。** 对透视投影求偏导，给出每个元素的单位和意义。理解 Jacobian 是均值附近的局部线性近似。
3. **推导二维协方差。** 先推线性变换 $A\Sigma A^T$，再将 $A$ 换成投影 Jacobian。明确透视投影下高斯不会一般性地精确变成高斯。
4. **理解像素贡献与遮挡。** 由屏幕椭圆计算像素处的高斯权重，再乘不透明度；手算两个半透明高斯的合成，交换深度顺序，解释颜色为何改变。
5. **补最少的体渲染背景。** 理解透射率、吸收和前向合成；认识体渲染离散权重的形式。不需要先复现 NeRF，但要能区分沿光线采样密度与投影 splat 的计算过程。

### 必须能推导的公式

设相机坐标 $\mu_c=R_{cw}\mu_w+t_{cw}=(X,Y,Z)^T$，则

$$
\pi(\mu_c)=\begin{bmatrix}f_xX/Z+c_x\\f_yY/Z+c_y\end{bmatrix},\quad
J=\begin{bmatrix}f_x/Z&0&-f_xX/Z^2\\0&f_y/Z&-f_yY/Z^2\end{bmatrix}.
$$

$$
\Sigma_c=R_{cw}\Sigma_wR_{cw}^T,\qquad
\Sigma_{2D}\approx J\Sigma_cJ^T.
$$

这里使用 2×3 的像素投影 Jacobian；读论文中的记号时，要核对其坐标和维度约定。

对像素 $p$，以 $o_i$ 表示第 $i$ 个高斯的不透明度参数，避免与像素 alpha 混淆：

$$
\alpha_i(p)=o_i\exp\left[-\frac12(p-\mu_{2D,i})^T\Sigma_{2D,i}^{-1}(p-\mu_{2D,i})\right],
$$

$$
T_i(p)=\prod_{j<i}(1-\alpha_j(p)),\qquad
C(p)=\sum_iT_i(p)\alpha_i(p)c_i+T_{\mathrm{end}}(p)C_{\mathrm{bg}}.
$$

求和按前到后排序。以上是便于理解的理想表达；实现中还包含稳定化、截断和提前终止。

### 小练习与验收

投影一个三维高斯，画屏幕椭圆；改变深度、旋转和尺度。可采样少量三维点作投影对照，过滤非正深度，比较小高斯与大高斯的近似误差。再写两个高斯的 alpha 合成。

通过标准：独立推导 $J$ 和 $\Sigma_{2D}$；正确手算两层混合；指出近相机、大尺度时局部近似的风险。交付两页推导及投影/混合图。

## 第 3 周：图像误差怎样改善场景？

**目标：理解参数更新与增密分别解决什么问题，走通一次训练迭代。**

论文阅读：精读第 5 节；对照附录 B 的优化和增密算法。附录 A 先看梯度结构，选一个简单路径推导。

### 五次学习

1. **把训练写成优化问题。** 明确相机、目标图像和可学习场景参数；理解 L1 与 D-SSIM 的分工，回顾梯度下降和 Adam 的作用。
2. **跟踪一条梯度路径。** 从损失到像素颜色，再到像素 alpha、二维均值、三维位置。复习偏导、链式法则和 Jacobian；解释遮挡为何影响梯度。
3. **理解参数约束。** 在实现中找到尺度的正值映射、opacity 的范围映射和旋转归一化。区分底层优化变量与渲染使用的实际参数。
4. **理解自适应密度控制。** 对照欠覆盖与过大高斯的图示，分别解释 clone、split、prune；核对视空间位置梯度和尺度如何参与判断。理解 opacity reset 的作用，避免把增密理解为可微公式。
5. **读一次完整训练迭代。** 画出采样训练视角、渲染、计算损失、反传、参数更新及按计划调整高斯数量的流程；记录实际代码里操作顺序。

### 小练习与验收

固定颜色和旋转，用 1–3 个二维高斯拟合一张小目标图，只优化位置、尺度和不透明度。先用单高斯和接近目标的初始化，避免将复杂拟合失败误当成公式错误。

对一个位置参数比较 autograd 与中心有限差分，选平滑且不跨排序/裁剪边界的设置。记录初始/最终图和损失曲线；CPU 即可。

通过标准：解释误差怎样传到位置和形状；解释为什么参数更新无法直接增加高斯数量；能针对两个示意场景说明更适合 clone 还是 split。损失下降并能解释结果即可，不要求恢复唯一真值参数。

## 第 4 周：为何它能实时？论文的证据是否支撑结论？

**目标：把表示、优化和高效渲染串起来，完成整篇论文的独立讲解。**

论文阅读：精读第 6、7 节；回读第 1–5 节；选择阅读附录 A、B、C。第 2 节只追踪与当前疑问直接相关的工作。

### 五次学习

1. **理解前向光栅化。** 画出视锥剔除、屏幕范围、tile 重叠、高斯复制到相关 tile、排序、逐像素混合和提前终止。区分算法上的近似深度排序与逐像素精确几何排序。
2. **理解反向渲染。** 理解为何需要高效遍历参与像素合成的高斯，前向保存什么信息、反向怎样获得参数梯度。说明“可微”是在给定可见集合与顺序下的连续计算；排序、剔除和增密不必全局光滑。
3. **建立公式—代码对照。** 在作者仓库定位参数定义、渲染入口、训练循环和增密函数；CUDA 部分只追踪投影、排序、混合、反传的职责。固定所读 commit；现代代码可能包含原论文之后的功能。
4. **读实验和消融。** 各选一项初始化、增密、各向异性或球谐消融，写“改变了什么、测量了什么、支持什么结论”。核对数据集、分辨率、训练时长、硬件与指标，区分画质与成本。
5. **闭卷讲解和补缺。** 用 15–20 分钟讲完整方法，再对照论文纠错。最终整理三页笔记：整体流程、核心公式、设计选择与局限。

### 验收问题

1. 单个高斯有哪些参数？如何形成有效协方差？
2. 为什么投影需要 Jacobian？这个近似在哪里可能失效？
3. opacity 参数与像素 alpha 有什么区别？遮挡怎样进入颜色计算？
4. 图像损失怎样影响位置、尺度和颜色？
5. clone、split、prune 分别解决什么问题？
6. tile、排序和提前终止分别节省了什么计算？
7. 球谐为何能表达方向相关外观？它有哪些表达限制？
8. 选择一项消融，说明它支持的结论以及不能据此推出的结论。

能独立回答以上问题，并现场推导投影 Jacobian、协方差传播和两层 alpha 混合，即达到这四周的主要目标。完整附录梯度与 CUDA 内核实现可作为后续深入方向。
