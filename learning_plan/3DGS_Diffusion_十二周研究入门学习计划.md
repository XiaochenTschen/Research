# 3DGS 与 Diffusion研究入门十二周学习计划

面向自动驾驶仿真与神经重建工程师

以现有 NuRec 和 NCore 数据流水线经验为起点，每周投入约 11 小时，恢复数学与深度学习基础，深入 3DGS，并完成小型 Diffusion 实践和一项受控研究。

三个月的预期成果

能够解释核心方法，将关键公式对应到代码，复跑基线、修改一个环节，并在指导下完成有对照实验的小研究。这是参与研究任务和向 Research Engineer 发展的准备，不等同于独立 Research Scientist 的完整任职条件。

投入与执行方式

每周约 11 小时：理论 3 小时，编码与实验 5 小时，验收 2 小时，记录与复盘 1 小时。GPU 等待时间不计入主动学习时间。

建议节奏：周二和周四各 1.5 小时；周六 4 小时；周日 4 小时。每周至少保留两个不学习的晚上。

每周完成一个可检查的产出。阅读和观看课程只算准备，代码、图表、推导及实验记录才是完成证据。

若每周只有 5–6 小时，将每一周任务分成两周。遇到基础缺口优先补齐，日期可顺延。

开始前的准备

准备独立的 Python 环境、Git 仓库、NumPy、Matplotlib 和 PyTorch；记录版本与随机种子。前四周的核心练习可用 CPU。

在第 5 周前确认可用的兼容 GPU 和所选 3DGS 实现要求。采用公开小场景、低分辨率和小模型，先做短跑再安排长实验。

默认具备基础 Python 与 NumPy 能力。若不能独立读写数组、编写函数和绘图，先增加 1–2 周准备期。

### 交付物

### 如何检验完成效果
